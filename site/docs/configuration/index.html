PERSONALIZAÇÃO

Configuração

Altere tema, fuso horário e destino dos arquivos sem editar o núcleo do gerador.

Novidade da Fase 2: configure tema, cores, fuso e saída num arquivo JSON opcional. Veja o guia de configuração por arquivo e o exemplo pronto. O personalizador já mostra seis templates SVG reais com dados fictícios e permite exportar cores; seleção de cards publicados, layout do README e largura de exibição já disponíveis; a edição interna de SVGs permanece planejada.

Parâmetros

ParâmetroOpçõesPadrão
--thememidnight, graphite, auroramidnight
--timezoneNome IANA, como America/MaceioUTC
--outputPasta de saídadist

Exemplo

python src/axr_stats.py --theme aurora --timezone America/Maceio --output dist

O código da Action expõe as entradas theme, timezone e output. Seus nomes devem corresponder aos da versão que você estiver utilizando.

Prévia dos cards

Abra o Theme Workbench para visualizar os seis SVGs gerados pelo Python com números fictícios. Ele recolore os sete tokens aceitos pelo JSON, sem alterar emblemas ou consultar o WakaTime. Você pode baixar um SVG de demonstração, mas não usá-lo como suas estatísticas pessoais.

Publicação e layout do README

No personalizador, escolha os cards que deseja publicar. O JSON exportado inclui cards (lista de nomes), layout (stacked ou paired) e size (compact, standard ou large). Quando há layout ou tamanho, a Action gera README-snippet.md com caminhos relativos aos cards publicados. Os SVGs mantêm sua geometria original e as credenciais ficam exclusivamente no GitHub Actions Secret.

Densidade do card de Linguagens

Na Fase 2.3.1, o campo language_rows controla quantas linguagens são exibidas: 5, 8 ou 10 (padrão). Isso altera o número de linhas e a altura do SVG, mas não modifica horas nem ranking. Experimente no personalizador.

Tipografia e estrelas de progresso

A Fase 2.3.2 aceita typography: compact (90%), standard (100%, padrão) e large (108%). O campo show_rank_stars aceita true ou false, controlando as estrelas nos cards Tempo total e Emblema. As artes originais não são alteradas, e os dados do WakaTime permanecem iguais. Experimente as prévias SVG no editor.

Cabeçalho dos cards

Use header_style com standard (título, subtítulo e barra lateral) ou minimal (título e divisor, sem subtítulo). A segunda opção muda apenas a apresentação interna; métricas e emblemas permanecem iguais. Veja os dois estilos no personalizador.

Temas disponíveis

Midnight — fundo azul-escuro com ciano; Graphite — grafite neutro com lilás; Aurora — verde-azulado com tons suaves. Esses temas se aplicam aos gráficos. O site possui visual editorial claro próprio.

Substituir um emblema

Os emblemas estão em assets/badges/current/ com nomes por tier: 01-iniciante.png até 12-soberano.png. Para inserir novos assets, use PNG transparente com margens equivalentes, dimensões padronizadas e o mesmo mapeamento por nível.

Preparado para as novas artes. Os doze PNGs atuais são a coleção original fornecida pelo mantenedor. A arquitetura permite novas coleções sem redesenhar os cards.

Credenciais

O token só deve ser fornecido via ambiente protegido do GitHub Actions. Nunca adicione autenticação ao JavaScript do GitHub Pages. Leia a política de segurança.
