Documentação

Tudo para configurar seus cards, compreender os dados e personalizar a evolução no GitHub — com controle sobre o que é publicado.

Estado atual: prévia pública. Os cards já funcionam no perfil de referência, mas a Action reutilizável ainda não possui release estável. Não existe uma tag v1 publicada.

O que é o AXR Stats?

Um gerador de cards que lê estatísticas autorizadas do WakaTime e exporta SVGs para o README do seu perfil GitHub. A evolução por rank é uma funcionalidade própria do AXR Stats, calculada com horas registradas.

O WakaTime informa atividade real; o AXR Stats organiza os dados e os apresenta em cartões. Nenhum ranking oficial é inventado.

Como funciona

  1. Seu editor registra atividade no WakaTime.
  2. O GitHub Actions executa o gerador com um token OAuth guardado em Secrets.
  3. A API oficial fornece métricas conforme as permissões concedidas.
  4. O gerador valida e escreve imagens no seu próprio repositório.
  5. Seu README incorpora essas imagens por caminhos relativos.
