Perguntas frequentes

Respostas objetivas para dúvidas de instalação, estatísticas e publicação.

Posso usar minha API Key do editor?

Não. Para leitura de estatísticas, use um token OAuth pessoal com permissão apropriada.

Por que as horas não coincidem?

O total de linguagens pode diferir do contador histórico, dependendo dos formatos reconhecidos e do processamento dos dados pelo WakaTime. Se um resultado disser “30 dias”, não o interprete como “all-time”.

Por que meu ranking não aparece?

O serviço pode não retornar uma posição pública confirmada. Nesse caso o card deve mostrar indisponibilidade sem inventar classificação.

Posso usar meu próprio emblema?

Sim. Os PNGs são independentes e podem ser substituídos. O restante do card continua com métricas reais.

O GitHub Pages aceita várias páginas?

Sim. Estas rotas são páginas estáticas reais, publicadas por arquivos index.html em diretórios individuais, sem servidor e sem roteamento de SPA.

Já existe versão pública estável?

Não. O projeto ainda está em prévia e não possui tag v1 estável. Consulte o roadmap antes de instalar a Action em um projeto de produção.

Onde relatar um problema?

Abra uma issue no GitHub, descrevendo o comportamento e os logs sem informações confidenciais.
