Instalação

Configure sua conta de forma segura e teste a geração local antes de automatizar publicações no GitHub.

Primeira vez usando GitHub Actions? Siga o guia para iniciantes, com os cliques necessários para instalar, proteger o OAuth, executar e publicar os cards.

Importante: não existe release @v1 ainda. O workflow de exemplo usa a referência mutável @main, adequada apenas para testes da prévia. Para produção, fixe um commit SHA revisado. O procedimento abaixo é apropriado para testar o código atual.

1. Prepare suas contas

Instale o plugin oficial do WakaTime no seu editor e confira se a atividade aparece no painel do WakaTime. Para ler estatísticas, crie seu token OAuth pessoal. A API Key usada pelo plugin do editor não serve.

2. Guarde o OAuth

No repositório de perfil do GitHub, acesse Settings → Secrets and variables → Actions e crie um segredo chamado WAKATIME_OAUTH_TOKEN. Não inclua esse valor em commits, logs, prints ou URLs.

3. Teste o gerador localmente

git clone https://github.com/axrobert/axr-stats.git
cd axr-stats
python -m pip install -r requirements-runtime.txt
python -m unittest discover -s tests -v

Depois de definir a variável de ambiente no seu terminal, gere os cards:

python src/run_action.py --theme midnight --timezone America/Maceio --output dist

Não publique seu segredo. O token precisa estar definido como WAKATIME_OAUTH_TOKEN somente no ambiente de execução; nunca o copie para um arquivo público.

4. Prepare a automação

O repositório tem um workflow de exemplo. Use a referência @main apenas em testes de prévia. Em produção, fixe um commit SHA completo e revisado; a tag v1 ainda não existe.

Teste externo comprovado: o repositório de perfil executou a Action com um SHA fixo e permissões contents: read, sem publicar os arquivos. Confira a execução validada no GitHub Actions. Para publicar os cards em seu próprio repositório, o workflow de exemplo requer contents: write.

Ao concluir a geração, a automação deve publicar exclusivamente os arquivos validados. O runner gera SVGs e PNGs numa pasta temporária, valida os oito arquivos e somente então publica. Erros de API anteriores à publicação preservam os gráficos existentes.
