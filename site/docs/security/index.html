REFERÊNCIA

Segurança e privacidade

O site de documentação não acessa sua conta, não lê seus arquivos privados e não recebe tokens. A automação roda no seu repositório.

Autenticação OAuth

O acesso à API oficial do WakaTime ocorre com um token pessoal OAuth fornecido ao GitHub Actions por meio de Secrets. API Keys de plugins de editor são usadas para registrar eventos, não como alternativa para ler estes dados.

Nunca publique o token. Não copie credenciais para README, arquivos versionados, parâmetros de URL, snippets, imagens ou código client-side.

Domínios e escopo

O gerador deve enviar o cabeçalho Authorization: Bearer apenas à API oficial do WakaTime. A documentação do GitHub Pages é estática e não contém infraestrutura de autenticação.

Dados expostos nos cards

Quando você publica os cards em um README, as métricas escolhidas ficam visíveis a qualquer pessoa: tempo total, linguagens, dias de atividade e eventual posição oficial. Antes de ativar a publicação, decida o que deseja mostrar.

Comportamento em falhas

O workflow deve interromper a geração se a API retornar dados inválidos ou incompletos, preservando imagens previamente aprovadas. Não registre tokens em mensagens de erro.

Revogação

Se suspeitar de vazamento, revogue e gere outro token OAuth no WakaTime e atualize o segredo no GitHub Actions. Confira também os logs e commits públicos.

Mais detalhes técnicos no arquivo de segurança do repositório.
