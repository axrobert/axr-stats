02 / REGISTRO DE MARCOS

Entregas e pendências

Filtre as fases por situação.

Exibindo as 5 fases.

  1. 00 / ORIGEMConcluída

    Protótipo

    Primeiros cards gerados a partir dos registros do WakaTime.

    • Leitura via OAuth do WakaTime
    • Cards de atividade, histórico, linguagens e ranking oficial
    • Progressão personalizada por horas registradas
    Ver o perfil original
  2. 01 / DISTRIBUIÇÃOEm andamento

    Action reutilizável

    O gerador ganhou repositório independente, CI e teste real como dependência de outro projeto. Falta concluir os requisitos da primeira release estável.

    • Teste externo com 6 SVGs + 2 PNGs validado
    • Publicação dos cards com validação antes da substituição
    • Pendentes: licença, arte final e auditoria da distribuição
    Ver teste externo aprovado
  3. 1.5 / EXPERIÊNCIAEm andamento

    Identidade visual

    Ajustes de navegação, layout, responsividade e documentação.

    • Site e documentação multipágina com pesquisa
    • 12 emblemas corrigidos recebidos; integração em revisão
    • QA de responsividade, navegação e acessibilidade
    Ver fundação visual no GitHub
  4. 02 / PERSONALIZAÇÃOEm andamento

    Personalização de cards

    Temas, cores, seleção de cards e layouts de README implementados. A Fase 2.3 inclui densidade de Linguagens, tipografia, estrelas e descrições de cabeçalho opcionais; outras composições seguem planejadas.

    • Arquivo JSON com sete tokens de cores e três temas
    • Seis prévias SVG reais e exportação de JSON
    • Seleção de cards, layout do README e largura de exibição
    • Layouts internos do SVG e tipografia ainda planejados
    Abrir personalização de temas
  5. 03 / PRODUTO PÚBLICOPlanejada

    Plataforma web

    Ampliar a experiência para além de um conjunto de arquivos gerados automaticamente.

    • Editor visual de cards e prévia no navegador
    • Guia de instalação e documentação multilíngue
    • Métricas opcionais do GitHub, com origem identificada
    Conheça a documentação
