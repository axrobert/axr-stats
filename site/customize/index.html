PERSONALIZAÇÃO / FASE 2 · PRÉVIA

Uma paleta. Seu estilo.

Ajuste cores, tipografia e elementos dos seis cards, depois exporte um axr-stats.json para usar com a Action. Os números exibidos são fictícios; as artes dos emblemas são preservadas.

01

Configurar cores

Escolha um ponto de partida e ajuste os tokens.

Seleção e apresentação

Selecione quais cards a Action publica e a disposição do snippet para o README. O desenho dos SVGs não é redimensionado internamente.

Cards para publicar

Ajusta a altura e a quantidade de linhas do SVG de Linguagens, sem alterar o histórico real.

Somente cores #RRGGBB. Nenhuma informação é enviada a servidores.

02

Prévia dos cards

Os seis SVGs do gerador Python, com dados fictícios.

Carregando prévias geradas pelo Python...

Exportar configuração

Inclui cards selecionados, organização do README e tamanho. Nunca inclua secrets.

{"theme":"midnight"}

Prévia do README

Copie este trecho para o README do seu perfil após executar a Action. Caminhos relativos consideram assets/axr-stats.

A prévia usa dados fictícios. Os cards publicados pela Action usarão suas métricas verificadas.

Como usar

Salve como axr-stats.json e informe config-path: axr-stats.json na Action, ou use python src/run_action.py --config axr-stats.json localmente. Documentação completa.
